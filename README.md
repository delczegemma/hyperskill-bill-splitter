# Bill Splitter 💸

A Python implementation of a restaurant bill splitting tool created as part of the
[Hyperskill Python Developer course](https://hyperskill.org/courses/2-python-developer).

[Project link](https://hyperskill.org/projects/175).

## About

The program was gradually developed through multiple stages, starting from a simple
bill division and ending with a random "who is lucky" feature. Invalid user input
is handled with exceptions, and duplicate guest names are rejected during input.

## Features

* Equal bill splitting among any number of guests
* Rounding to two decimal places
* Input validation for the guest count and the bill value
* Optional "Who is lucky?" feature, where one randomly chosen guest pays nothing
